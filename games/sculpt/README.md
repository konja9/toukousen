# 等高線 — SCULPT

等高線シリーズ第 2 作。地形模型を盛って・削って斜面をつくり、球を転がしてゴールの穴へ入れるパズル。
Three.js 製。モノクロ。

> 盛って、削って、転がす。

第 1 作（フライトゲーム CONTOUR GLIDE）はリポジトリのルートにあり、このディレクトリとは独立しています。

## 遊び方

- 80 m 四方の地形模型が等高線（1 m 間隔、5 m ごとに太線）で描かれています。
- **地形をいじって斜面をつくり、球をゴールの穴へ転がします。** 球は放すまで動きません。
- **土は増えも減りもしません。** 盛る（盛土）には土が要り、削る（切土）と土がたまります。左の SOIL ゲージが手持ちの土です。
- 白く光る線は、球と同じ高さの等高線です。その内側は球より高い地面です。
- 編集中は、球が最初の数秒に転がる道すじが点線で出ます。
- 水面より下へ入ると沈みます（SUNK）。点描の岩盤は削ることも盛ることもできません。△ の水準点を通ってからでないとゴールに入りません。
- 評価はストローク数（ドラッグした回数）です。PAR 以下なら ★3、PAR+2 以下なら ★2 です。失敗しても地形はそのまま残るので、何度でも直して転がせます。
- 図葉（ステージ）は 10 枚で、どれからでも遊べます。最少手数はブラウザに保存されます。

### 操作（PC / マウス＋キーボード）

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 盛土（土を積む） |
| 右ドラッグ / `Shift`＋左ドラッグ | 切土（土を削る） |
| ホイール / `[` `]` | ブラシの大きさ |
| `Space` | 球を放す / 転がり中なら止めて編集に戻る |
| `F`（押している間） | 早送り ×4 |
| `Z` | ひとつ戻す |
| `R` を 2 回 | ステージを最初から |
| `Q` / `E` | 視点を 90° 回転 |
| `V` / `Tab` | 真上から見る ⇄ 斜めから見る |
| `1`–`9`, `0` | 図葉を番号で開く |
| `Esc` | 図葉一覧へ |
| `M` / `T` | 音 / 夜と紙のテーマ |

## 起動

```bash
cd games/sculpt
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイル（base: './'）
npm test           # ユニットテスト＋全ステージの解答検証
npm run typecheck
```

WebGL2 対応ブラウザが必要です。

## 仕組み

- **高さ場**：81×81 の制御点（1 m 間隔）を一様 3 次 B スプラインで補間した曲面です（`src/field/heightfield.ts`）。GPU でも同じ式で描くので、等高線はなめらかで、見た目と球の物理がずれません。`?selftest` を付けて開くと、GPU と CPU の値を比較します。
- **ブラシ**：ガウス分布で盛り・削りをします。盛った分だけ手持ちの土が減り、削った分だけ増えます。岩盤は動かず、高さは 0〜40 m に収まります。
- **球**：斜面方向の重力（転がる球なので 5/7 倍）と転がり抵抗で動きます。120 Hz の固定ステップで決定的に計算します（`src/sim/ball.ts`）。
- **ステージ**：丘・窪み・尾根・溝などの組み合わせで地形を作り、それぞれに解答（ストロークの記録）を持たせています（`src/sim/stages.ts`）。`tests/stages.test.ts` で全ステージについて次を確認しています。
  - 何もしなければ解けない
  - 解答で PAR 以内に解ける
  - 位置と時間を少しずらした解答でも解ける（操作が多少雑でも通る余裕があること）
- **見た目**：浮かんだ等高線模型として描きます。側面には地層のような水平線、水面にはハッチを入れています。図葉一覧のサムネイルは CPU のマーチングスクエアで描いています。

## 構成

```
src/
  config.ts          調整値（地形・ブラシ・球）
  field/             高さ場（B スプライン・ブラシ・土量・アンドゥ）、レイピック
  sim/               球の物理、ステージ定義、ストローク再生、地形プリミティブ
  render/            模型（地表・側面・水）、球やゴールなどの印、カメラ、GLSL
  ui/                HUD（Canvas 2D）、画面（タイトル・一覧・結果）、サムネイル、CSS
  game/game.ts       状態機械（タイトル → 一覧 → 編集 ⇄ 転がり → クリア/失敗）
  core/              入力、WebAudio 合成音、保存、イージング
  debug/selftest.ts  GPU / CPU 一致テスト（?selftest）
tests/               vitest
```
