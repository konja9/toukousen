# 等高線 — DEAD GROUND

等高線シリーズ第 3 作。等高線の地図を読んで見張りの死角（デッドグラウンド）をつなぎ、見つからずにコントロールを回るステルス・オリエンテーリング。
Three.js 製。モノクロ。

> 見られずに、読んで、走れ。

第 1 作（フライトゲーム CONTOUR GLIDE）はリポジトリのルート、第 2 作（地形パズル SCULPT）は `games/sculpt/` にあり、このディレクトリとは独立しています。

## 遊び方

- 480 m 四方の地形を、肩越しの三人称視点で走ります。地上も地図も等高線（5 m 間隔、25 m ごとに太い計曲線）だけで描かれています。
- **スタート △ から、コントロール ①②③… を番号順に回り、フィニッシュ ◎ へ。** コントロールに近づくと自動でパンチされます。タイムを競います。
- 各コントロールには「頂上」「鞍部」「窪地」などの説明が付いています。地図と地形の形を照らし合わせて探します。
- **見張り塔**の光（扇形）は、首を振るか、ぐるりと回ります。**巡回**は丘のまわりを歩き、前方を見ています。
- 見張りから見えている地面には斜線が掛かります。そこに入って見られ続けると警戒ゲージが溜まり、満タンで **SPOTTED**。直前のコントロールへ戻され、30 秒が加算されます。戻った直後の 2 秒間はゲージが溜まりません。
- 斜線の外、尾根や丘の陰が死角です。ただし尾根ぎわで立っていると頭が見えることがあります。伏せれば（目の高さ 0.6 m）陰の中は安全です。疾走すると足音が近くの見張りに聞こえます。
- 地図（`M` / `Tab`）を開いている間も時間は止まりません。地図には見張り塔の射程と巡回路も描かれています。
- **通常モード**では地図に現在地 ▲ が出ます。**読図モード**では出ないので、方位と地形の形だけで自分の位置を判断します。
- 図葉（コース）は 8 枚で、どれからでも遊べます。図葉×モードごとのベストタイムがブラウザに保存され、一度も見つからずに完走すると **UNSEEN** 印が付きます。

### 操作（PC / マウス＋キーボード）

| 操作 | 動作 |
| --- | --- |
| `W` `A` `S` `D` | 移動（カメラの向きが基準） |
| マウス | 視点（クリックでポインタロック。使えない環境ではドラッグ） |
| `Shift`（押している間） | 疾走 |
| `C` / 左 `Ctrl` | 伏せる ⇄ 立つ |
| `M` / `Tab` | 地図を開く・閉じる |
| `Esc` | 一時停止（図葉一覧・ブリーフィングでは戻る） |
| `R` | 最初からやり直す |
| `Space` | 決定 / 開始 / 次の図葉へ |
| `1`–`8`、矢印キー | 図葉を選ぶ |
| `G` | 通常モード ⇄ 読図モード（図葉一覧で） |
| `T` / `N` | 夜と紙のテーマ / 音 |

## 起動

```bash
cd games/deadground
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイル（base: './'）
npm test           # ユニットテスト＋全図葉の検証（隠れ道・自動操縦での完走）
npm run typecheck
```

WebGL2 対応ブラウザが必要です。

## 仕組み

- **地形**：ノイズ（fbm と ridged）から 241×241 の格子（2 m 間隔）を作り、一様 3 次 B スプラインで補間した曲面です（`src/field/`）。GPU の地形シェーダも同じ式で高さを計算するので、足もとの高さ・視線判定・描かれる等高線がずれません。
- **見える範囲**：見張りごとに、その目から見た地形の深度マップを 1 枚のアトラスに描き（最大 6 基）、地形シェーダで「見張りから見えている地面」を判定して斜線を掛けます（影の描画と同じ手法、`src/render/viewshed.ts`）。ゲームの判定は CPU 側で、見張りの目から自分の頭まで高さ場の上を少しずつ進めて視線が通るかを調べます（`src/field/los.ts`）。`?selftest` を付けて開くと、GPU の表示と CPU の判定の一致率を確認します。
- **特徴抽出**：格子の臨界点をヘッセ行列で分類し（頂上・窪地・鞍部）、目立たないものを除いたうえで、コントロールの位置と説明に使います（`src/field/features.ts`）。
- **コース**：自動生成器（`src/sim/design.ts`）が地形の特徴にコントロールを置き、コースを見下ろす頂上に塔を、丘のまわりに巡回路を置きます。選んだ結果は `tools/freeze.test.ts`（`npm run freeze`）で `src/sim/courses.ts` にデータとして固定しているので、生成器を直しても公開済みの図葉は変わりません。
- **検証**（`tests/courses.test.ts`）：全図葉について次を確認しています。
  - 各コントロールが、説明どおりの地形の特徴の上にある
  - 見張りに見られている時間の割合をマス目ごとに求め、見られやすい所ほど高くつく最短路探索で、スタートからフィニッシュまで、見られている時間が 6 割を超える地面を通らずに回れる道がある。スタートとフィニッシュはほとんど見られない場所にある
  - その道を、ゲームと同じ規則（移動・斜面・見張りの動き・警戒ゲージ・復帰）で走る自動操縦が、見つかる回数 2 回以内で完走できる。PAR はこの自動操縦の走行時間から決めています
- **見た目**：地上は背景色で塗った面に等高線だけを描く隠線処理の見た目です。地図は全画面の 2D 地図シェーダと Canvas 2D の重ね描き（コース・記号・現在地）です。

## 構成

```
src/
  config.ts          調整値（地形・プレイヤー・見張り）
  field/             高さ場（B スプライン）、地形生成、特徴抽出、視線判定、露出マップと経路探索
  sim/               プレイヤー、見張り、コース定義（8 図葉）、コース生成・検証、自動操縦
  render/            地形（等高線＋見える範囲）、見張りの深度マップ、紙の地図、人・塔・扇・旗、追従カメラ、GLSL
  ui/                HUD（Canvas 2D）、画面（タイトル・一覧・ブリーフィング・結果）、サムネイル、CSS
  game/game.ts       状態機械（タイトル → 一覧 → ブリーフィング → 走行 ⇄ 地図 → 発見 → フィニッシュ）
  core/              入力、WebAudio 合成音、保存、ノイズ、乱数、イージング
  debug/selftest.ts  GPU / CPU 一致テスト（?selftest）
tests/               vitest
tools/               コース作成用（AUTHORING=1 のときだけ実行。npm run freeze）
```
