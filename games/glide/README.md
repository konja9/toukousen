# 等高線 — CONTOUR GLIDE

等高線だけで描かれた無限の地形を、グライダーで滑空するスコアアタック。
2 km ごとのチェックポイントで時間をつなぎ、尾根の上昇風を拾いながら、図葉ごとの課題に挑みます。
Three.js 製。モノクロ。

> 線を読め。低く飛べ。遠くへ。

等高線シリーズ第 1 作。シリーズの他の作品は `games/` の下に並んでいます（一覧はリポジトリのルートの README）。

## 遊び方

- 地形は等高線（10 m 間隔、50 m ごとに太い計曲線）だけで描かれています。
- **白く光る線は、いまの自機と同じ高さの等高線**です。その内側の斜線で塗られた地形は自分より高い＝ぶつかる場所。線を読んで飛ぶコースを決めます。
- **地面に近いほどスコア倍率が上がります**（対地高度 30 m 未満で ×2、16 m 未満で ×3、8 m 未満で ×4）。
- 谷に沿って浮かぶ**リング（ゲート）**を抜けると加点と加速。連続で抜けると CHAIN が伸び、ボーナスが増えます。外すと CHAIN はリセット。
- 立ちのぼる**同心円の柱は上昇気流（サーマル）**。中に入ると高度を回復できます。
- 物理はエネルギー交換型です。降下すると加速し、上昇すると減速します。遅くなりすぎると失速して機首が下がります。
- 進むほど山は高く、谷は狭く、谷底は荒れていきます。地図（SHEET 番号）は毎回変わり、同じ番号なら同じ地形です。

### 制限時間とチェックポイント

- 持ち時間は 45 秒から始まります。**2 km ごとのチェックポイント**（谷を横切る水平線の幕）を通ると時間が加わります。加わる時間は奥へ行くほど短くなります（35 秒 → 28 秒）。
- 0 になると **TIME UP** で終わりです。高く安全に飛んでいると間に合いません。高度を速度に換え、ゲートの加速と風を使って飛びます。
- チェックポイントでは、その区間のタイムと、その図葉での最速との差、次の区間の風と**ゲートの並び**（CENTER LINE / SLALOM / LOW LINE / RIDGE LINE）が表示されます。

### 風と尾根の上昇風

- 区間ごとに、谷を横切る向きの風が吹いています（6〜13 m/s、奥ほど強い）。風向きと風速はレーダーの左に出ます。
- **風上を向いた斜面の上には上昇風、風下の斜面には下降風**が出ます。斜面に近いほど強く、斜面が急なほど強くなります。風上の壁ぎわを低く滑ると高度とエネルギーを稼げますが、風下の壁ぎわは沈むので危険です。
- 地表近くを流れる**気流の筋**は、上昇風の所では上へ、下降風の所では下へ傾きます。
- **昇降計（バリオメーター）**の音：上昇気流の中では電子音が鳴り、強いほど高く速くなります。強い下降気流の中では低いうなりが鳴ります。高度計の下に空気の上下の速さ（`AIR ↑2.4` など）も出ます。

### 図葉ごとの課題とメダル

- 各図葉（SHEET 番号）には決まった 3 つの課題があります（例：「ゲートを 8 連続で抜ける」「対地 8 m 未満を 400 m 続ける」「尾根の上昇風で 180 m 昇る」）。
- 達成するとその図葉のメダル（◆）になり、記録されます。タイトル画面で `←` `→` を押すと図葉を変えられ、その図葉の課題と達成状況が出ます。
- 飛行中は、スコアの下に課題の進み具合が出ます。

### 操作の手応え

- **ニアミス**：自機と同じ高さの地形が横 7 m 以内に迫ったまま飛び抜けると、`NEAR MISS +50 × 倍率`。
- ゲートを抜けた瞬間に視野が広がり、速いときや地面すれすれのときは画面の外側に速度の線が出ます。

### 操作（PC / キーボード）

| キー | 動作 |
| --- | --- |
| `W` `S` / `↑` `↓` | 上昇 / 降下（`Y` で上下反転） |
| `A` `D` / `←` `→` | 旋回（バンク） |
| `Shift` | エアブレーキ |
| `Space` / クリック | 開始（クリックはタイトル画面のみ） / 結果画面から新しい地図へ |
| `←` `→` | 図葉を変える（タイトル画面） |
| `R` | 同じ地図で再挑戦 |
| `Esc` / `P` | ポーズ |
| `Q` | タイトルへ（ポーズ中・結果画面） |
| `M` | サウンド ON/OFF |
| `T` | 白黒反転（夜 / 紙の地形図） |

タイトル画面では、マウスを地図の上に置くとその地点の標高が表示されます。

## 起動

```bash
cd games/glide
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイルを出力（base: './' なので任意の場所に置ける）
npm run preview    # ビルド結果の確認
npm test           # ユニットテスト + バランステスト
npm run typecheck
```

WebGL2 対応ブラウザが必要です。

## 仕組み

- **高さ関数の二重実装** — 地形の高さ `h(x, z)` は GLSL（`src/world/shaders/height.glsl`）と TypeScript（`src/world/terrainField.ts`）の両方に同じ式で実装しています。描画は GPU、衝突判定・ゲート配置・レーダーは CPU。2D simplex noise のハッシュ計算は `Math.fround` で float32 に揃えてあり、`?selftest` を付けて開くと GPU と CPU の高さを 16,384 点で比較します（誤差 0.07 m 程度）。
- **等高線シェーダ** — フラグメントシェーダでピクセルごとに高さを再計算し、`fract(h / 10)` と `fwidth` でアンチエイリアスされた一定幅の線を描きます。線が密になりすぎる所はフェードしてモアレを防止。自機高度の線と、それより高い領域の斜線もここで描きます（`src/world/shaders/contour.glsl`）。
- **3D と 2D** — 飛行中はプレイヤー中心の変位メッシュ（中心ほど頂点が密）、タイトル・レーダー・結果画面の地図は同じ関数を使う全画面クアッドで描画しています。面は背景色で塗って奥の線を隠す、いわゆる隠線処理の見た目です。
- **調整値** — 地形・物理・スコアの定数は `src/config.ts` に集約。地形の定数は GLSL に `#define` として注入されるので、ここを変えれば GPU と CPU の両方に反映されます。
- **尾根の上昇風** — 上下の風速は `風速 × 風向きに沿った斜面の傾き × exp(−対地高度 / 45 m)`（上昇側 0.9 倍、下降側 0.55 倍）。斜面の傾きは高さ関数の中心差分で求めます（`src/world/wind.ts`）。気流の筋は同じ式を GLSL でも実装して頂点シェーダで傾けており（`src/world/airflow.ts`）、`?selftest` は高さに加えてこの上下の風速も GPU と CPU で比較します。
- **区間** — 2 km ごとの区間に、風（向き・強さ）とゲートの並べ方が図葉番号から決定的に割り当てられます（`src/world/sectors.ts`）。ゲートは並べ方によらず、リングの下半分が地形に埋まらない高さに置きます。
- **バランステスト** — `tests/balance.test.ts` の簡易オートパイロット（ゲートを結ぶ線を谷に沿ってたどる）が、5 つの地図で制限時間に追われながら 4 区間・8 km 以上を墜落せずに飛べることを確認します。逆に、地形から 70 m 上を安全に飛ぶだけでは 3 区間以内に TIME UP になることも確認しています。
- **保存** — localStorage に `toukousen:best`（最高点）、`toukousen:medals`（図葉ごとの課題の達成）、`toukousen:splits`（図葉ごとの区間の最速）などを保存します。

## 構成

```
src/
  config.ts              調整値（地形・物理・スコア・風・制限時間）
  main.ts                エントリ
  game/                  状態機械（タイトル → 降下 → 飛行 → 墜落 / TIME UP → 結果）、スコア、制限時間とニアミス、課題
  world/                 高さ関数、地形メッシュ、2D 地図、サーマル、ゲート、区間と風、気流の筋、チェックポイント、GLSL
  player/                グライダーの物理と線画モデル
  camera/                俯瞰 ⇄ 追従カメラの補間
  ui/                    HUD（Canvas 2D）、DOM 画面、CSS
  core/                  入力、WebAudio 合成音、保存、イージング
  debug/selftest.ts      GPU / CPU の高さと上昇風の一致テスト（?selftest）
tests/                   vitest
```
