# 等高線 — SOUNDING

等高線シリーズ第 4 作。真っ暗な海をソナーの音で測りながら潜っていく、潜航ローグライク。
Three.js 製。モノクロ。

> 音で測れ。聞かれる前に。

第 1 作（フライトゲーム CONTOUR GLIDE）は `games/glide/`、第 2 作（地形パズル SCULPT）は `games/sculpt/`、第 3 作（ステルス・オリエンテーリング DEAD GROUND）は `games/deadground/` にあり、このディレクトリとは独立しています。

## 遊び方

- 潜水艇を後ろから見る 3D 視点で操縦します。海の中は真っ暗で、何も見えません。
- **`Space` でソナーを打つと、音の波が球状に広がり、届いた海底に等深線（10 m 間隔、50 m ごとに太線）が浮かびます。** 尾根の裏は影になり、照らされません。光った等深線は数秒で薄れますが、測った海底は海図に残ります。
- ソナーの音は遠くまで聞こえます。
  - **哨戒艦**に聞かれると捜索が始まります。
  - 相手が打ったソナーの波が自分に届くと**探知**され、爆雷が降ってきます。深い区画では、魚雷を撃つ潜水艦も出てきます。
  - 相手のソナーの波も海底を照らします（破線で描かれます）。自分は音を立てずに、それで周りを見ることもできます。
  - 相手がソナーを打つと、その位置が海図に記録されます。
- **躍層**：
  - ある深さに水温の境目があり、そこをまたぐ音は届く距離が半分になります。
  - 3D 視点でも海図でも、破線の等深線が躍層の深さです。
  - 海底が躍層より深い谷筋に沿って進めば、海面の哨戒艦に見つかりにくくなります。
  - 尾根（敷居）を越えるときは躍層の上に出るので、そこが危険な場所です。
- 画面の補助表示：
  - 自分と同じ深さの等深線は、明るく太く描かれます（ぶつかる壁の位置）。
  - 自分より高い海底には斜線が掛かります。
  - 画面右端の深度計に、自分の深さ・真下の海底・躍層が出ます。
- 速く進むほど機関の音が遠くまで届き、電池も早く減ります。海底をこすったり、壁にぶつかったりしても音が出て、船体が傷みます。
- **各区画の降下口（海溝）を見つけて潜れば、次の区画へ進みます。**
  - 降下口のおおよその位置は、海図に破線の円で出ています。
  - 途中の測点（沈没船・熱水噴出孔・海山頂）をソナーで照らすと記録され、電池が回復します。
- 区画を抜けるたびに、改装を 3 つから 1 つ選びます：静音スクリュー、高出力ソナー、指向性ソナー、囮、船体補強、大容量電池、残響記憶、受動ソナー強化。
- 区画が進むと、次の順に敵が加わり、躍層は深く、谷は狭くなります：哨戒艦（区画 3〜）、聴音ブイ（区画 5〜）、猟犬潜水艦と機雷（区画 7〜）。
- 船体が尽きると圧壊して終わりです。
  - 航海記録には、各区画の海図と航跡（躍層の上に出た区間は太線）が並びます。
  - 潜航ごとにシード番号（DIVE #0421 など）があり、`R` で同じ海にもう一度潜れます。
  - 最高記録（通過区画数と最大深度）はブラウザに保存されます。

### 操作（PC / キーボード＋マウス）

| 操作 | 動作 |
| --- | --- |
| `W` `S` / `↑` `↓` | 速力の段階を上げる・下げる（停止・微速・半速・全速） |
| `A` `D` / `←` `→` | 左右に曲がる |
| `Q` `E`（押している間） | 浮上 / 潜航 |
| `Space` | ソナーを打つ（タイトル・結果画面では決定） |
| `F` | 指向性ソナー（改装後） |
| `X` | 囮を放つ（改装後） |
| マウスドラッグ | 視点を回す（離すと後方に戻る） |
| `M` / `Tab` | 海図を広げる・戻す（時間は止まらない） |
| `1` `2` `3` | 改装を選ぶ |
| `Esc` | 一時停止 |
| `T` / `N` | 夜と紙のテーマ / 音 |

## 起動

```bash
cd games/sounding
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイル（base: './'）
npm test           # ユニットテスト＋区画生成の検証＋自動操縦での完走
npm run typecheck
```

WebGL2 対応ブラウザが必要です。

## 仕組み

- **海底**：
  - 241×241 の格子（2.5 m 間隔、600 m 四方）を、一様 3 次 B スプラインで補間した曲面です。GPU のシェーダも同じ式で深さを計算します（`src/field/`）。
  - 格子の値は、ノイズ（広い起伏と、しわのような細い谷の網）に、区画ごとの谷・敷居・海山・降下口の海溝を彫り込んで作ります。
- **区画の生成と検証**（`src/sim/sector.ts`）：
  - 区画は（シード, 区画番号）から実行時に作ります。
  - 4 m 間隔の格子で、次の重み付けの最短路を探し、入口から降下口まで隠れて進める道があるかを調べます（`src/field/path.ts`）。
    - 海底が躍層より十分深いマスは、隠れて通れるので安く
    - それ以外のマスは高く
  - 次の条件を満たさない区画は、パラメータを変えて作り直します：
    - 躍層の上に出る長さが範囲内
    - 降下口が十分に深い
  - 哨戒艦は、道が躍層の上に出る場所のまわりを巡回します。機雷は、道から離れた脇の谷に置きます。
- **ソナー**（`src/field/echo.ts`）：
  - ソナーを打つと、射程内の海底のマスを近い順に処理し、波が届く時刻までに発信点からの見通しを調べます。
  - 見通しが通ったマスに「波が届いた時刻」を書き込みます。
  - この時刻は float テクスチャとして GPU に送ります。地形シェーダは「いま − 届いた時刻」から、波の先端の閃光と残光を描きます。
  - 測った範囲は海図のマスクにもなります。
- **敵**（`src/sim/contacts.ts`, `src/sim/world.ts`）：
  - 哨戒艦・聴音ブイ・猟犬潜水艦は、同じ状態機械（巡回 → 捜索 → 追跡 → 見失う → 巡回に戻る）で動きます。
  - 聞こえる距離は音の大きさで決まり、躍層をまたぐと半分になります。
  - 探知は、相手のソナーの波が自分に届いた瞬間に判定します（射程・躍層・海底による見通し）。
  - すべて時刻と入力だけで決まるので、テストで再現できます。
- **検証**（`tests/`）：
  - シード 1〜50 × 区画 1〜10 のすべてで、条件を満たす区画が作れること（平均 160 ms 程度）。
  - 道を知っている自動操縦（`src/sim/bot.ts`）が、区画 1〜6 を圧壊せずに抜けられること。
  - ソナーの反響（影・到達時刻・扇形）、聴音と躍層、地形による遮蔽、捜索の打ち切り、爆雷の被害。
- `?selftest` を付けて開くと、次の 2 点を GPU と CPU で照合します。
  - 海底の深さ
  - ソナーで光る範囲

## 構成

```
src/
  config.ts          調整値（海底・潜水艇・ソナー・敵・進行）
  field/             高さ場（B スプライン）、海底生成、4 m 格子の検索と見通し、ソナーの反響
  sim/               潜水艇、敵、区画の生成と検証、1 区画の世界、潜航全体、改装、テスト用の自動操縦
  render/            海底（等深線＋反響の光）、ソナーの波、線画の模型、海図、追従カメラ、GLSL
  ui/                HUD（Canvas 2D）、画面（タイトル・改装・航海記録）、航海記録の海図、CSS
  game/game.ts       状態機械（タイトル → 潜航 ⇄ 海図 → 区画通過 → 改装 → … → 圧壊）
  core/              入力、WebAudio 合成音、保存、ノイズ、乱数、イージング
  debug/selftest.ts  GPU / CPU 一致テスト（?selftest）
tests/               vitest
```
